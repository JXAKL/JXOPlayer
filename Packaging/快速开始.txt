JXOPlayer 2.0.2 · Windows 蓝牙组件替换测试版
构建日期：2026-11-06

安装
双击 JXOPlayer-2.0.2-Setup.exe，选择安装位置即可。
默认安装到当前用户目录，不需要管理员权限。
也可使用免安装 ZIP：完整解压后运行 JXOPlayer.exe，不要在压缩包内直接启动。
适用于 Windows 10 2004（19041）及以上、Windows 11 64 位，
已附带运行环境、Windows 蓝牙接口组件、PotPlayer 和媒体时长读取组件。

首次使用
1. 在设备设置中选择并连接自己的设备，按设备情况设置轴范围与回零位置。
2. 在本地脚本库中添加脚本目录；在“视频库”中添加视频及脚本所在目录。
3. 扫描完成后，可用低、较低、中、较高、高按钮随机播放。默认使用 PotPlayer。
4. 音频不参加随机播放，仍可用 PotPlayer 手动播放并匹配同名脚本。
5. 自动联播默认关闭，可按需开启。悬浮窗默认开启，可拖动、折叠和调整透明度。

这份发行版不包含原使用者的媒体库、缓存、播放记录、设备地址、账号信息、
个人轴设置、窗口位置、日志或测试文件。所有个人设置需首次使用时重新设置。
安装不会导入其他目录里的旧配置。升级本发行版时保留已有配置。
卸载会移除已安装的程序文件和快捷方式，保留使用后产生的设置及日志。

文件名兼容
保留中文、日文、英文、表情和特殊字符，按同名及已有时长规则匹配脚本。
从 JXOPlayer 打开超长路径视频时会自动兼容；使用本机读取通道期间请保持
JXOPlayer 运行。直接拖入 PotPlayer 的超长路径仍受 PotPlayer 自身限制。

设备连接
USB：串口列表不再只识别 CH340 名称。CP210x、CH34x、ESP32 原生 USB
等设备只要在 Windows 中显示有效 COM 端口，就可以手动选择。
多个 COM 端口时需在 USB 串口设置中选择自己的设备；波特率需与固件一致。
若 Windows 设备管理器也没有 COM 端口，需检查 USB 数据线和对应串口驱动。
蓝牙：先打开 Windows 蓝牙，展开播放器设备列表并选择自己的设备。
经典蓝牙需要 SPP 服务；也可先在 Windows 配对后选择对应的蓝牙 COM 端口。
BLE 支持 FFE0 服务/FFE1 特征和 Nordic UART 服务，需要固件通过该服务接收 TCode。
发现设备名称不代表固件协议兼容；没有对应可写特征时会明确提示。
2.0.2 已用 Windows 蓝牙接口替换旧 BLEDriverCore.dll，发行包不再携带或依赖
该调试版组件，不需要安装 Visual Studio 或复制调试版 VC++ 运行库。
连接等待、发送等待有上限，关闭会取消等待并释放连接；BLE 数据按 MTU 分包发送。
已验证组件加载、枚举、失败恢复和反复关闭，尚未完成实际 ESP32 BLE 收发验证。
WiFi：在高级连接中填写设备实际的局域网 IPv4 地址和固件配置的 UDP 端口。
手动连接不再强制要求 D1/TCode 握手回复；UDP 显示已连接代表本机发送通道
已建立，不能据此确认设备已经收到。电脑与设备需在可互通的网络中。
自动发现仍保留原有设备识别规则；第三方固件请先使用手动连接。

自带的 PotPlayer 及其解码组件许可文件保留在 PotPlayer 目录中。
